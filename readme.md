# 🤖 AI Chatbot using Flask & Gemini API

A simple AI chatbot web application built using **Flask**, **HTML/CSS/JavaScript**, and **Google Gemini API**.

The chatbot can:

- answer user questions in real-time

- maintain chat history

- provide a clean interactive chat interface

---

# 🚀 Features

- Real-time AI responses

- Gemini API integration

- Flask backend API

- Interactive chatbot UI

- Chat history management using JSON

- Frontend-backend communication using Fetch API

- Responsive chatbot design

---

# 🛠️ Tech Stack

## Frontend

- HTML

- CSS

- JavaScript

## Backend

- Python

- Flask

- Flask-CORS

## AI Model

- Gemini 2.5 Flash Lite
